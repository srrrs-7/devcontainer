# Todo アプリケーション 画面仕様書

## 1. 概要

### 1.1 目的
シンプルで直感的なタスク管理を実現するWebアプリケーションの画面仕様を定義する。

### 1.2 デザイン原則
- **シンプリシティ**: 必要最小限の要素で最大の生産性を実現
- **即時フィードバック**: ユーザーアクションに対する即座の視覚的レスポンス
- **アクセシビリティ**: キーボード操作、スクリーンリーダー対応
- **レスポンシブ**: デスクトップ・モバイル両対応

### 1.3 データモデル
```typescript
type Task = {
  taskId: string;           // UUID
  userId: string;           // ユーザーID
  content: string;          // タスク内容（最大1000文字）
  completedAt: string|null; // 完了日時（null=未完了）
  version: number;          // 楽観的ロック用バージョン
  createdAt: string;        // 作成日時
  updatedAt: string;        // 更新日時
};

type TaskStatus = "PENDING" | "IN_PROGRESS" | "COMPLETED";
```

```

│  🏠 Todo App                                              👤 user@email.com │
│                                                              [Sign Out]     │
```

| 要素 | 説明 |
|------|------|
| ロゴ/タイトル | アプリケーション名、クリックでホームへ |
| ユーザー情報 | 現在ログイン中のユーザーメールアドレス |
| サインアウト | ログアウトボタン |

### 3.2 タスク作成フォーム

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  New Task                                                                   │
│  ───────────────────────────────────────────────────────────────────────    │
│                                                                             │
│  ┌───────────────────────────────────────────────────────────────────┐      │
│  │  Enter task content...                                            │      │
│  └───────────────────────────────────────────────────────────────────┘      │
│                                                               123/1000      │
│                                                                             │
│  ❌ Task content is required                     (エラー時のみ表示)        │
│                                                                             │
│                                                      [➕ Add Task]          │
└─────────────────────────────────────────────────────────────────────────────┘
```

| 要素 | 説明 | バリデーション |
|------|------|----------------|
| テキスト入力 | タスク内容の入力フィールド | 必須、最大1000文字 |
| 文字数カウンター | 現在の文字数 / 上限 | 上限超過時は赤色表示 |
| エラーメッセージ | バリデーションエラー表示 | 入力エラー時のみ表示 |
| 追加ボタン | タスク作成実行 | 空欄時は非活性 |

#### 状態遷移
```
[通常] ──入力開始──> [入力中] ──送信──> [送信中] ──成功──> [通常]
                         │                  │
                         │                  └──失敗──> [エラー表示]
                         │
                         └──1000文字超過──> [エラー状態（赤枠）]
```

#### ステータス別表示

| ステータス | アイコン | バッジ色 | テキスト装飾 | 背景色 |
|------------|----------|----------|--------------|--------|
| PENDING | ☐ | outline (グレー枠) | なし | 通常 |
| IN_PROGRESS | ⏳ | secondary (薄い色) | なし | 通常 |
| COMPLETED | ✅ | default (塗りつぶし) | 取り消し線 | 薄いグレー |

| 操作 | 動作 |
|------|------|

| ステータス変更 | ドロップダウンで即時更新 |
| Editボタン | 編集モードに切り替え |
| Deleteボタン | 削除確認ダイアログ表示 |

## 7. アクセシビリティ

### 7.1 キーボード操作

| キー | 動作 |
|------|------|
| Tab | 次のインタラクティブ要素へ移動 |
| Shift + Tab | 前のインタラクティブ要素へ移動 |
| Enter | ボタン押下、フォーム送信 |
| Escape | 編集モードキャンセル、ダイアログ閉じる |
| Space | チェックボックストグル、ボタン押下 |

### 7.2 ARIA属性

```html
<!-- タスクリスト -->
<ul role="list" aria-label="Task list">
  <li role="listitem" aria-labelledby="task-content-1">
    ...
  </li>
</ul>

<!-- ステータスバッジ -->
<span role="status" aria-live="polite">
  COMPLETED
</span>

<!-- 削除確認ダイアログ -->
<dialog role="alertdialog" aria-labelledby="dialog-title">
  ...
</dialog>
```
